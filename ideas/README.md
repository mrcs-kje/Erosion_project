# Ideas inbox

Everything Marcus sends that might become part of Erosion.exe: videos, links, screenshots, notes, code references, concepts.

One file (or folder) per idea, named with the date and a short name, for example `2026-10-21_scroll-erosion.md`. Write down what it is, where it came from, and how it could be used. When an idea becomes an experiment, note the experiment folder (`site/erosion/<name>/`) in its file.

Discussed in the "Ideas inbox" thread.

The running list of all ideas is `IDEAS.md` in this folder.
