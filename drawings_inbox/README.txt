DRAWINGS INBOX (for DRAWINGS / DUMP 02, site/erosion/sketch/)

Drop drawings here: your own, collaborators', found things.
Photos, scans, PNG, JPG, SVG. Any size, any name.

Then tell Claude in the thread "Redesign the drawing dump" (or the project chat).
Claude makes a web-sized copy in site/erosion/sketch/drawings/, adds a line
to site/erosion/sketch/drawings.js, and the drawing turns up somewhere on the
endless sheet, in a new place on every visit.

Optional: put a drawing in a subfolder named after who made it
(for example drawings_inbox/marcus/ or drawings_inbox/<collaborator>/).
Names are not shown on the site for now, but are kept for later.

This folder stays on the PC (not in git), like assets/.
Only README.txt is tracked.
