# Website mockups (inspiration only, not decisions)

Pictures of how Erosion.exe could look. None of this is fixed. The site does not have to be a scrollable grid; Erosion may break normal design and UI rules.

- `erosion_home.png`, `erosion_room.png`, `erosion_mobile.png`: first aesthetic studies (home, a room, phone).
- `erosion_page_nest/raw/sketch/game/loop.png`: five hypothetical pages.
- `erosion_random_piece.png`: one invented piece with deliberately bad crops and scale.
- `sitemap/`: a hypothetical map of pages and links, including how crawlers spread.
- `sources/`: the HTML that draws each mockup.

Look: near-black, off-white, one orange line, small uppercase status labels. Glitch is allowed but is not the design philosophy.
